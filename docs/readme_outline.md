# Rates, Risk & Returns
An interactive dashboard showing how the 2021-23 inlation shock and the rise in interest rates that followed affected economies, investments and what a saver's money could grow to.
## The four panels
| # | Panel | Chart | Owner |
|---|-------|-------|-------|
| 1 | The global shock | Animated bubble chart | Ciara Feeney |
| 2 | Who wins when rates move? | Bar chart witg a rate-shock slider | Eoin Cunningham |
| 3 | Build the best portfolio | Efficient frontier | Conall Mooney | 
| 4 | What could it become? | Monte Carlo fan chart | Hannah McElligott |
